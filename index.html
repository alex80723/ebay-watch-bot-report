📐 評分準則 (rubric.md)

評分準則 v0.2（starter rubric）

用途：給 LLM 評分器使用。對每則 eBay 新上架商品給出 0–100 分與簡短繁體中文評語。 來源：FB 社團「Allen Ray = NBA 球衣世界 =」社團簡介 + ~8 則近期商品貼文觀察。 狀態：v0.2（v0.1 → v0.2 重構為「主題式」而非「球員式」組織）。 待累積 ~50 次出手 / 略過決策後依實際偏好微調。

1. 商品定位

賣家以「絕版、原版、復古、稀有」為核心。主打：

  • 老牌或熱門球員的 原版（AU / 球員版 / 緞面 AU） 球衣
  • 球員賽前周邊：練習衣、熱身衣、投籃服
  • 復古外套：Champion、Jordan、Nike、adidas 1990s–2000s 風衣、夾克、Space Jam 系列
  • 球隊網訂製、官網限定、期間限定的版本
  • 明星賽、奧運、總冠軍等紀念性單品
  • 「異色」「電繡包邊」「緞面」等做工 / 材質升級款

核心訴求：每件商品都有自己的故事，外面找不到。

等級 範圍 備例

⚑ 核心原則

球員熱度為加成項，永不作排除依據。

任何球員都有可能成為高分商品 — 評分以「主題契合 + 真偽 + 狀態 + 故事性」為主軸。 明星球員（Kobe、Jordan、LeBron、Wemby、KD 等）能加分但非必要條件。 冷門球員若在主題與真偽上強，仍可獲得 80+ 高分。

舉例：

  • Tony Parker（球員熱度低）+ 歐版 AU 馬刺絕版緞面（主題 A + C 強）→ 仍可 80+
  • Kobe（球員熱度極高）+ 普通 Swingman + 條件差 → 約 50–60，球員熱度不會把整體拉高

主題契合判斷規則：

  • 商品強符合 1 個主題 → 主題分滿分起點 70+
  • 商品同時涵蓋 2 個主題 → 主題分起點 80+（如 Wemby 法國練習衣 = B + E）
  • 商品同時涵蓋 3+ 主題 → 主題分起點 85+（如 1996 美國奧運 Champion 風衣 = A + B + D）

4. 真偽 / 品質訊號

正面 (+)

  • 製造特徵清晰：贊助標（MAIF、Stubhub、Rakuten 等）燙印清楚平整
  • 字體與年代相符：例如 LeBron Heat 2010 球員實戰版幾乎全為 R30；早期短窗口才有緞面舊版
  • 多角度細節照：領標、洗標、車線、燙印特寫、吊牌特寫
  • 尺寸實測：衣長、腋下寬度、肩寬等具體數據
  • 賣家評價：98%+ 且 ≥ 500 則評價
  • 吊牌存在 OR 合理缺席：練習衣本來無吊牌可接受；號稱「全新球員版」卻無吊牌則需懷疑

負面 (–)

  • 吊牌看起來太新，但商品標榜為老品
  • 字體 / 商標版本與年代不符（如 2010 後球衣卻用 1990s 字體）
  • 燙印歪斜、邊緣翻起、染印模糊
  • 賣家圖庫風格不一致（疑似轉售拼湊）
  • 同一賣家近期上多件「稀有」高價品但細節照都很少
  • 描述用「應該是」「我猜」「不附保證」等推諉用語

5. 評分權重

因素 權重
主題契合度（A–E 五大主題） 30%
真偽可信度 25%
球員熱度（純加成，不作排除） 20%
狀態 / 稀缺度 / 故事性 15%
價格相對台灣市場 10%

重要說明：

  • 「球員熱度」只能加分，不能將分數壓到排除門檻以下
  • 球員冷門時，分數應由主題 / 真偽 / 故事性撐起；不可因球員不熱而扣到 50 以下
  • 反之，球員熱門但其他維度都弱時（如 Kobe Swingman 普品狀況差），分數不會因球員身分被拉高到 80+
  • 真偽訊號模糊時應扣分；寧可錯失也不要推送疑似仿品
  • 賣家擅長以故事創造價值 — 即使球員 / 球隊偏冷，若有強敘事框架（如「實著款」「短窗口」「異色限定」）仍可獲中高分

  • score：0–100 整數

  • rationale：1–2 句繁體中文，明確指出主題契合與加分扣分主因

8. 待補充（v0 → v1 過程中累積）

以下項目目前憑社團定位與小樣本推測，需以實際 50+ 次出手 / 略過決策資料修正：

  • 「主題契合度」的判定一致性 — LLM 是否能穩定識別 A–E 主題
